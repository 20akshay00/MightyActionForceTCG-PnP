# Data

`original_cards.json` is the game's card list, generated by `extract.py pnp` and not tracked. `cards.json` holds custom
cards in the same format; an entry with the same `id` and `style` as an original replaces it.

Each card appears once per style it exists in: `clean` (red deck) or `worn` (yellow deck). A clean-only card such as
Omegon is reused in the worn frame when a worn deck needs it. Fields:

- `id`: snake_case name, used in `decks.json`.
- `style`: `clean` or `worn`.
- `name`, `value`: title and badge number (any single digit).
- `badge` (optional): hex colour for the badge, overriding the value's colour in `assets/svg/badges/badges.json`.
- `effect`: `none`, `block`, `steal`, `draw`, `skip` or `both`. Effect cards print `power_name` and `description`,
  others print `quotation`. Effects are only text; the rules are in the booklet.
- `art`: a path under `assets/`. Paths in `svg/art/` are original art; other images fill the picture window.

`decks.json`: each player's ten-card deck and style, plus the shared extras.

`rules.json`: the reveal order and the five effects, with a short text for the turn card and a longer one for the
booklet. The rest of the booklet is in `templates/rules/`.

# Assets

`fonts/` and most of `svg/` are generated by `extract.py pnp` and not tracked. Tracked: the measurements
(`frames/frames.json`, `badges/badges.json`) and `svg/added/`, the pieces drawn for this version. `img/` holds the
logo, which you add yourself.

Frames, art and badges are in card units (280 × 400, origin top left). Art is drawn around its own origin and placed
at the card centre (140, 200). Everything else is placed by its bounding box, measured in Chrome and cached in
`.cache/bounds.json`.

| File | What |
| --- | --- |
| `svg/frames/clean.svg`, `worn.svg` | Card frame without its badge: clean (red deck) and worn (yellow deck) |
| `svg/badges/badge_4.svg` | The value badge, recoloured for every value except 6 |
| `svg/badges/badge_6.svg` | Omegon's rainbow badge |
| `svg/badges/badge_1.svg`–`badge_3.svg` | The game's other badges, used only by the original-card preview |
| `svg/art/<id>.svg` | Character art |
| `svg/backs/clean.svg`, `worn.svg` | Card backs |
| `svg/pieces/gem_red.svg`, `gem_yellow.svg` | Score gems |
| `svg/pieces/arrow_large.svg`, `arrow_small.svg` | Card-back arrows, used on the tuck box and booklet |
| `svg/added/card_frame.svg` | Frame and panel behind the turn cards and scoreboard |
| `svg/added/scoreboard_back.svg` | Scoreboard back |
| `fonts/` | Grilled Cheese (titles, numbers), Billy Serif (text), Creative Block (labels) |
| `img/logo_card_game.png` | The logo, from the [Poptropica Wiki](https://poptropica.fandom.com/wiki/Mighty_Action_Force_Card_Game) |

`frames.json`: the picture window (`art_box`) and the card's corner radius.

`badges.json`: `palette` holds each value's `light`, `dark` and `outline` colours; missing shades are derived from
`light`, and values without an entry are grey. `base` is the badge that gets recoloured, `special` lists values with
their own badge. `card_ring` is where the badge's disc sits on the card and `rings` where it sits in each badge file,
so any badge lands in the same spot. `corner_scale` sizes the upside-down corner badge, and `digits` holds per-number
offsets that centre the value on the badge's star.

The badges keep the game's digits, tagged `class="dg"` and hidden in print; the value is drawn as text instead.
